This week I started at Disco Tray Studio, working on **SocialHXAuth**, part of the studio's social prescription platform. It's a .NET/C# project, which was new to me, so a big part of the week was learning how the codebase is organized while shipping real changes.

## What I worked on

- **Referral page, Prescription Page, 1st Week Follow Up Page, 4th Week Follow Up Page:** added student name and email fields, so each page now records who it's for and how to reach them.

All changes went through my fork and pull requests so a teammate could review them before merging.

## What I learned

- How a .NET web project is structured: pages, models, and how data flows between them
- Working in a real team workflow: forks, branches, PRs and code review
- Reading an existing codebase before changing it instead of starting from scratch
